# Keymouse Productions — Site institucional

Site institucional da Keymouse Productions, estúdio independente de software, tecnologia e criação.

Endereço: https://joaomanop.github.io/

## Estrutura do site

- / — página inicial do estúdio e visão geral do ecossistema.
- /products/ — catálogo e filtros por área.
- /products/milens/ — página da suíte criativa Milens.
- /products/simueng/ — página do laboratório educacional SimuEng.
- /products/autoeng/ — página da plataforma técnica AutoEng.
- /studio/ — apresentação do estúdio, áreas de atuação e processo.
- /journal/ — caderno editorial, visão de produto e área reservada para comunicados e notas de versão.
- /support/ — central de informações, disponibilidade e perguntas frequentes.
- /404.html — página de endereço não encontrado.

## Produtos apresentados

- **Milens** — suíte criativa local-first para vídeo, imagem, áudio e 3D. Site público: https://milens.com.br/
- **SimuEng** — laboratório educacional para eletrônica, circuitos 2D/3D, aprendizagem guiada e projetos com Raspberry Pi.
- **AutoEng** — plataforma em desenvolvimento para arquitetura e engenharia, conectando planta, modelo 3D, instalações e informações da obra.

O site distingue capturas reais de interface de esquemas ou ilustrações conceituais. SimuEng e AutoEng estão identificados como projetos em desenvolvimento; o site não inventa downloads, canais ou changelogs ainda não publicados.

## Tecnologias

HTML, CSS e JavaScript estáticos, sem etapa de compilação ou dependência de framework. A publicação é feita pelo GitHub Pages.

- index.html — página inicial.
- assets/site.css — sistema visual compartilhado e responsivo.
- assets/site.js — navegação móvel, filtros de catálogo, acordeões e seleção da página atual.
- assets/mark.svg — símbolo da Keymouse.
- assets/keymouse-mascot.svg — mascote do estúdio.
- assets/projects/ — capturas dos projetos.

## Publicação

O repositório deve usar GitHub Pages na branch main, diretório raiz.

Arquivos de descoberta e indexação: sitemap.xml e robots.txt.
